# WHEN STARS FADE — Electronic Press Kit

A free, responsive one-page EPK prepared for GitHub Pages.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub, for example `when-stars-fade`.
2. Upload `index.html` and the entire `assets` folder (keep the folder structure).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main`, folder `/ (root)`, then Save.
6. After GitHub finishes publishing, the site will be available at:
   `https://YOUR-USERNAME.github.io/when-stars-fade/`

## What to edit
- `index.html` — all text, links and layout.
- `assets/band-photo.jpg` — band photo.
- `assets/when-stars-fade-logo.png` — logo used on the page and offered for download.

Search in `index.html` for `replace` and update the placeholder links and email.
The biography currently contains a short provisional draft plus a marked note for details that still need confirmation.
